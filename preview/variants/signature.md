Backend engineer at [Smith.ai](https://smith.ai). Python, Django, Docker and Postgres in
production; whatever the problem actually needs everywhere else.

Lately most of what I ship points at the same thing: AI coding agents are doing real work
on real machines, and almost nobody can see what they are doing while they do it. So I
build the screens that show it — and the switch that makes them wait.

## Work

**[agentglass](https://github.com/SirAllap/agentglass)** &nbsp;[![stars](https://img.shields.io/github/stars/SirAllap/agentglass?style=flat-square&label=%E2%98%85&color=0d9488&labelColor=21262d&cacheSeconds=3600)](https://github.com/SirAllap/agentglass/stargazers) &nbsp;`Bun` `SQLite` `React` `Electron`<br>
Every AI coding agent on your machine, on one screen. Live cost, tokens and tool calls
across Claude Code, Codex, Gemini CLI and OpenCode — and a hold on anything dangerous
until you say go. It attaches to the tmux sessions and repos you already have open, and
nothing leaves the machine. Desktop app, signed Android APK, 22 themes, MIT.

**[waybar-scripts-collection](https://github.com/SirAllap/waybar-scripts-collection)** &nbsp;[![stars](https://img.shields.io/github/stars/SirAllap/waybar-scripts-collection?style=flat-square&label=%E2%98%85&color=0d9488&labelColor=21262d&cacheSeconds=3600)](https://github.com/SirAllap/waybar-scripts-collection/stargazers) &nbsp;`Python`<br>
CPU, GPU, memory, storage, network and weather modules for Waybar — the ones I actually
run every day, not a demo.

**[quickshell-popups](https://github.com/SirAllap/quickshell-popups)** &nbsp;`QML`<br>
The same readouts as native, theme-aware popups for Omarchy / Hyprland.

**[ccusage-gnome](https://github.com/SirAllap/ccusage-gnome)** &nbsp;`JavaScript`<br>
Claude Code spend, live in the GNOME top bar. A number you can't see is a number you
don't manage.
